# YOLOv8n 추가 학습 (semih_world 전용)

사전학습 YOLOv8n은 이 월드의 가방(`backpack_1`)을 대부분의 방향에서 suitcase/umbrella로 봅니다. 그래서 `target_classes:=backpack`으로는 원래 시작 위치 말고는 목표를 잡지 못했습니다(`docs/semiH_troubleshooting_log.md` 14절). 이 폴더는 Gazebo에서 사진을 자동으로 모으고 라벨을 만들어 YOLOv8n을 추가 학습하는 도구입니다.

결과 가중치는 `models/semih_yolov8n_ft.pt`입니다. 웹 대시보드(semiH_web)도 2026-11-18부터 이 모델을 씁니다(`semiH_web/config/settings.yaml`의 `perception.yolo_model_path`). 다른 월드나 실제 카메라에서는 이 값을 `yolov8n.pt`로 되돌리세요. 클래스 이름은 COCO 80개를 그대로 쓰므로, 노드의 `target_classes` 설정은 바꾸지 않아도 됩니다.

```bash
ros2 run semih_perception target_3d_node --ros-args \
  -p model_name:=$HOME/semiH_ws/models/semih_yolov8n_ft.pt \
  -p target_classes:=backpack -p confidence_threshold:=0.2
```

## 방법

1. **수집** (`collect_dataset.py`, 시뮬레이션이 떠 있어야 합니다)
   - Gazebo `set_pose`로 로봇을 가방·여행가방·의자 주변 무작위 위치로 옮깁니다. 거리는 0.55~3.5m, 방향은 360°, 물체가 화면 안에 오도록 ±26° 범위에서 돌립니다.
   - 무작위 위치·방향 사진도 함께 모읍니다.
   - 위치마다 RGB 사진과 깊이 영상을 저장합니다.
2. **자동 라벨** (사람이 상자를 그리지 않습니다)
   - 깊이 영상의 각 픽셀을 월드 좌표로 바꿉니다. 그 점이 물체 위치 반경 안이고 바닥보다 높으면 그 물체의 픽셀로 봅니다.
   - 이 영역을 감싸는 상자를 라벨로 씁니다. 가려진 경우에는 깊이 값 덕분에 보이는 부분만 상자가 됩니다.
   - 120픽셀보다 작은 영역은 라벨을 만들지 않습니다.
   - `preview/`의 상자 그림으로 라벨을 확인했습니다.
3. **학습** (`train.py`)
   - `yolov8n.pt`에서 시작합니다. 사진의 15%는 검증용으로 뺍니다.
   - 설정: 640px, 60 epoch(patience 20). 37 epoch째 모델이 가장 좋았고, 57 epoch에서 조기 종료됐습니다.
   - RTX 4070 Laptop에서 약 6분 걸렸습니다.
4. **평가** (`evaluate.py`)
   - 다른 시드로 따로 모은 시험용 사진을 씁니다. 학습에 쓰지 않은 위치들입니다.

## 결과 (2026-11-18)

- 데이터: 학습·검증용 1,237장(라벨 backpack 465, suitcase 603, chair 570), 시험용 325장.
- 시험 기준: 신뢰도 0.2, IoU 0.5, 1,500px² 이상인 라벨만 채점합니다.

| | 사전학습 YOLOv8n | 추가 학습 |
|---|---|---|
| backpack 검출률 | 0.120 (14/117), 놓친 것 대부분은 suitcase로 봄 | **1.000** (117/117) |
| suitcase 검출률 | 0.368 | 1.000 |
| chair 검출률 | 0.645 | 0.987 |
| 오검출 (backpack / suitcase / chair) | 0 / 64 / 13 | 2 / 3 / 0 |

추가 학습 모델의 오검출 수에는 채점에서 뺀 작은 라벨을 맞힌 경우가 들어 있지 않습니다. 이런 경우는 backpack 4건, suitcase 15건이었습니다.

### 전체 파이프라인 재시험

조건은 원래 시험과 같고(`target_classes:=backpack`, 신뢰도 0.2), 모델만 바꿨습니다.

| 시작 위치 | 사전학습 모델 | 추가 학습 모델 |
|---|---|---|
| 원래 위치 (가방 기준 158°, 1.2m) | 목표 고정 → 접촉 | backpack 0.77~0.97로 고정 → 접촉 |
| 다른 8곳 (90°~270°, 0.9~2.0m) | 8곳 모두 고정 실패 | **8곳 모두 고정 → 접촉** (backpack 0.45~0.98) |

- 접촉은 `arm_link3` 접촉 센서로 확인했고, 9곳 모두 `backpack_1`과만 닿았습니다.
- IK가 관절 한계에 걸린 곳(clamp)은 1곳(270°)입니다.

## 한계

- **이 월드의 이 물체 3개에 맞춘 모델입니다.** 다른 가방, 다른 조명, 실제 카메라 영상에서의 성능은 확인하지 않았습니다.
- 학습 데이터에는 backpack·suitcase·chair 라벨만 있습니다. 그래서 사람 등 다른 COCO 클래스의 성능은 유지된다고 보장할 수 없습니다(확인하지 않음).
- 시험용 사진도 같은 월드, 같은 물체에서 찍었습니다. 학습과 겹치지 않는 것은 로봇 위치뿐입니다.
- 학습 데이터에는 팔을 뻗은 장면이 없습니다.

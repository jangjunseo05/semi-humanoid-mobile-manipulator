## 2. 쓸 수 있는 결과 수치 (조건과 함께)

| 항목 | 결과 | 반드시 함께 적을 조건 |
|---|---|---|
| 반복 시험 | **같은 시작 위치 10회 중 10회 가방 접촉** | Gazebo 시뮬레이션. 접촉은 접촉 센서로 확인. 이 월드 사진으로 추가 학습한 YOLOv8n 사용. 신뢰도 0.2. 파지 없음 |
| 다른 시작 위치 | **8곳 모두 검출·접촉** (가방 기준 90°~270°, 거리 0.9~2.0m. 원래 위치를 포함하면 9곳) | 추가 학습 모델 기준이다. 사전학습 모델로는 원래 위치에서만 동작했다 |
| YOLO 추가 학습 | 학습에 쓰지 않은 위치의 시험 사진에서 backpack 검출률 **12% → 100%** (suitcase 37% → 100%, chair 64% → 99%) | 같은 시뮬레이션 월드·같은 물체로 잰 값이다. 사진 라벨은 깊이 영상으로 자동 생성했다 |

## 3. 프로젝트 설명에 쓸 수 있는 개선 내용 (문제 → 원인 → 해결)

1. **팔이 가방에 닿지 않음**
   - 원인: 처음 생각한 "거리"가 아니라 팔 설계였다. 관절 한계 때문에 팔 끝이 z 0.125m 아래로 내려가지 못했다.
   - 해결: 끝 링크를 0.15m에서 0.21m로 늘렸다. 멀리서 검출한 좌표를 저장한 뒤 그 좌표로 접근하게 했고, 팔꿈치를 먼저 접는 순서로 팔을 뻗게 했다.
2. **"2cm 앞에서 멈춘다"는 결과의 정체**
   - 접촉 센서를 달아 확인해 보니 실제로는 닿아 있었다.
   - 2cm는 팔 끝 좌표를 링크 중심축에서 쟀기 때문에 생긴 값이다. 링크 반지름이 1.6cm다.
3. **다른 방향에서는 인식이 안 됨**
   - 원인: 사전학습 YOLO가 이 가방을 suitcase나 umbrella로 봤다.
   - 해결: Gazebo에서 사진을 자동으로 모으고 깊이 영상으로 라벨을 만들어 YOLOv8n을 추가 학습했다. 이후 9곳 모두 성공했고 10회 반복도 10/10이었다.

## 4. 쓰지 말아야 할 표현

- "실제 로봇에서 동작" / "실환경 검증" — 시뮬레이션만 했다.
- "물체를 집는다" / "모바일 매니퓰레이션 완성" — 파지 기능이 없다. 도달(reach)과 접촉까지만 한다.
- "성공률 100%" / "YOLO 인식 완벽"을 조건 없이 쓰기 — 같은 시뮬레이션 월드, 같은 물체에서 잰 값이다.
- "어느 환경에서든 인식" — 추가 학습 모델은 이 월드 전용이다. 다른 가방, 실제 카메라, 사람 등 다른 클래스는 확인하지 않았다.
- "가방 표면 앞 2cm에서 정지" — 이전 표현이다. 지금은 "가방에 접촉(접촉 센서 확인)"으로 쓴다.
- "10회 중 9회" — 이전 시험(옛 모델, 센서 없음)의 수치다. 지금은 10/10을 쓴다.
- "대시보드에서 목표를 찍어 주행" / "대시보드 전체 중지" — 목표는 스크립트로 보냈고, 대시보드에 전체 중지 버튼은 없다.

## 5. STEP3 카드 '한계' 줄 제안

> 한계: Gazebo 시뮬레이션에서만 확인했다. 이 월드 사진으로 추가 학습한 YOLOv8n으로 같은 시작 위치 10회 중 10회, 다른 시작 위치 8곳 모두 가방에 접촉했다(접촉 센서 확인). 추가 학습 모델은 이 월드의 물체에 맞춘 것이라 다른 가방·실제 카메라에서는 확인하지 않았고, 사전학습 모델로는 원래 위치에서만 동작했다. 파지(grasp)는 구현하지 않았다.
